# Consultas y demostraciones PostgreSQL

- `fase_4_1_reportes.sql` contiene 18 reportes estrictamente de lectura.
- `fase_4_1_crud_demo.sql` muestra CRUD, joins, subconsultas y vistas dentro de un rollback.
- `fase_4_1_transacciones_demo.sql` documenta FK, rollback, concurrencia e idempotencia.

Los archivos de demostración no forman parte de las migraciones ni se ejecutan automáticamente.
