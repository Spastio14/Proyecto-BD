# Backend FastAPI

La aplicación usa Python 3.12, FastAPI, SQLAlchemy 2 y Psycopg 3 contra el
esquema canónico de `supabase/migrations`. No crea tablas ni ejecuta DDL.

Consulta `docs/arquitectura/backend-fase-2.md` para la instalación base y
`docs/arquitectura/supabase-fase-3.md` para Auth, Storage, poolers, secretos y el
preflight remoto.
